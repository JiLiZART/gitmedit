## REMOVED Requirements

### Requirement: Live subject length
**Reason**: The editor's premise is staying out of the way. A live character count is an opinion
about the message being written, and it occupies the status bar space the command bar needs.
**Migration**: None. Subject length conventions are enforced by review and by commit hooks, not by
the editor.

### Requirement: Subject length is colored by convention
**Reason**: Removed with the character count it colored.
**Migration**: None.

### Requirement: Missing blank separator is surfaced
**Reason**: Same rationale — an opinion about the user's message rather than a property of the file
git needs back. git itself does not require the separator.
**Migration**: None.
