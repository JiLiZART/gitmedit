    - `detect_context(Path::new("COMMIT_EDITMSG"))` returns `GitContext::Commit`
    - `detect_context(Path::new("MERGE_MSG"))` returns `GitContext::Merge`
    - `detect_context(Path::new("git-rebase-todo"))` returns `GitContext::Rebase`
    - `detect_context(Path::new("SQUASH_MSG"))` returns `GitContext::Squash`
    - `detect_context(Path::new("TAG_EDITMSG"))` returns `GitContext::Commit` (treated same as commit)
    - `detect_context(Path::new("unknown.txt"))` returns `GitContext::Unknown`
    - Detection uses only `Path::file_name()` — no content inspection
  </behavior>
  <action>
Create `src/context.rs` with:

1. A `GitContext` enum with variants: `Commit`, `Merge`, `Rebase`, `Squash`, `Unknown`. Derive `Debug`, `Clone`, `PartialEq`.

2. A `pub fn detect_context(path: &Path) -> GitContext` function that:
   - Calls `path.file_name()` to extract only the filename component (strips directory path)
   - Matches the filename string against: `"COMMIT_EDITMSG"` | `"TAG_EDITMSG"` → `Commit`, `"MERGE_MSG"` → `Merge`, `"git-rebase-todo"` → `Rebase`, `"SQUASH_MSG"` → `Squash`, anything else → `Unknown`
   - Uses `OsStr::to_str()` for the match; returns `Unknown` if the filename is not valid UTF-8

3. A `#[cfg(test)]` module with unit tests covering all six behavior cases above.
