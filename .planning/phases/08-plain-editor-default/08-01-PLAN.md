<objective>
Introduce the `EditorMode` enum on `Document` and update `parse`, `editable_lines`, and `serialize` so that:

- Commit (`EditorMode::Plain`) treats Comment AND ConflictMarker lines as editable; serialize emits textarea lines verbatim.
- Merge (`EditorMode::Merge`) treats ConflictMarker as editable; Comment stays protected; serialize re-injects Comment verbatim and emits ConflictMarker from textarea.
- Squash (`EditorMode::Squash`) is unchanged — only `Content` is editable; serialize re-injects Comment + ConflictMarker.

Implements D-01, D-02, D-03, D-04, D-05 from `.planning/phases/08-plain-editor-default/08-CONTEXT.md`. Caller wiring (`App::new`) and counter removal are handled in plans 03 and 02 respectively.

Purpose: This is the single source-of-truth change. All downstream behavior in `App::new` (Plan 03) flows from the EditorMode flag landing on Document here.

Output: `src/document.rs` with new `EditorMode` enum, mode-aware parse, mode-aware editable_lines, mode-aware serialize, and updated/new inline tests proving each mode's behavior.
</objective>
