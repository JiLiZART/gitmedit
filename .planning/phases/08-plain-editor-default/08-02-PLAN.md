<objective>
Remove the 50-char subject-line counter and the "[No blank line]" warning from both the commit status bar (`render_status_bar`) and the squash status bar (`render_squash_status_bar`). Delete the now-unused helper functions `counter_color_for` and `blank_warning_span` and their tests. Implements D-06 from `08-CONTEXT.md` ("Remove the 50-char subject-line counter and the 72-char body-line warning across all modes — no per-mode exception").

Purpose: Subject-counter and blank-line warning are noise in a plain-editor model. Removing them simplifies the chrome and frees a render slot for the nano-style command bar in Phase 9.

Output: `src/renderer.rs` with two simplified status-bar functions, two deleted helpers, and tests trimmed accordingly. No behavior change in commit/squash content rendering — only the status bar shrinks.

This plan is independent of Plan 01 (no file overlap, no shared symbols) and runs in parallel.

fn render_squash_status_bar(frame: &mut Frame, app: &App, area: Rect) {
    let first_line = app.document().first_line();
    let char_count = first_line.chars().count();
    let counter_color = counter_color_for(char_count);
    let counter_text = format!("Length: {}", char_count);
    let counter_span = Span::styled(counter_text,
        Style::default().fg(counter_color).add_modifier(Modifier::BOLD));
    let has_blank = app.document().has_blank_line_after_subject();
    let blank_warning = blank_warning_span(has_blank);
    let actions_span = Span::raw("  |  ^S Save  Esc Cancel  ^H Help  [Squash]");
    let status_line = Line::from(vec![counter_span, blank_warning, actions_span]);
    let status_widget = Paragraph::new(status_line)
        .style(Style::default().fg(Color::White).bg(Color::DarkGray));
    frame.render_widget(status_widget, area);
}
