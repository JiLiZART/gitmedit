Add the necessary imports at the top of main.rs:

use ratatui_textarea::CursorMove;

The complete match structure should look like:
```rust
let event = crossterm::event::read()?;
match &event {
    Event::Key(KeyEvent { code, modifiers, kind: KeyEventKind::Press, .. }) => {
        match (*code, *modifiers) {
            (KeyCode::Char('s'), KeyModifiers::CONTROL) => { /* save */ }
            (KeyCode::Esc, _) => { /* cancel */ }
            (KeyCode::Char('u'), KeyModifiers::CONTROL) => {
                app.textarea_mut().move_cursor(CursorMove::Head);
                app.textarea_mut().delete_line_by_end();
            }
            (KeyCode::Char('z'), KeyModifiers::CONTROL) => { app.textarea_mut().undo(); }
            (KeyCode::Char('y'), KeyModifiers::CONTROL) => { app.textarea_mut().redo(); }
            (KeyCode::Char('w'), KeyModifiers::CONTROL) => { app.textarea_mut().delete_word(); }
            (KeyCode::Char('d'), KeyModifiers::CONTROL) => { app.textarea_mut().delete_next_word(); }
            (KeyCode::Char('c'), KeyModifiers::CONTROL) => { /* clipboard copy - Task 2 */ }
            (KeyCode::Char('x'), KeyModifiers::CONTROL) => { /* clipboard cut - Task 2 */ }
            (KeyCode::Char('v'), KeyModifiers::CONTROL) => { /* clipboard paste - Task 2 */ }
            _ => { app.textarea_mut().input(event); }
        }
    }
    _ => {} // Ignore non-key events (mouse, resize handled by autoresize)
}
```

IMPORTANT: The `Esc` match must use `(KeyCode::Esc, _)` — do not require empty modifiers, as some terminals send modifiers with Esc.

**Step 1: Implement clipboard operations in `src/main.rs` event loop.**

Fill in the clipboard match arms from Task 1:

**Ctrl+C — Copy selection to system clipboard:**
```rust
(KeyCode::Char('c'), KeyModifiers::CONTROL) => {
    // Use textarea's internal copy first to populate yank buffer
    app.textarea_mut().copy();
    // Bridge yank buffer to system clipboard
    if let Ok(mut clip) = arboard::Clipboard::new() {
        let _ = clip.set_text(app.textarea().yank_text().to_string());
    }
    // Silent no-op if clipboard unavailable (SSH, headless)
}
```

**Ctrl+X — Cut selection to system clipboard:**
```rust
(KeyCode::Char('x'), KeyModifiers::CONTROL) => {
    app.textarea_mut().cut();
    if let Ok(mut clip) = arboard::Clipboard::new() {
        let _ = clip.set_text(app.textarea().yank_text().to_string());
    }
}
```

**Ctrl+V — Paste from system clipboard:**
```rust
(KeyCode::Char('v'), KeyModifiers::CONTROL) => {
    if let Ok(mut clip) = arboard::Clipboard::new() {
        if let Ok(text) = clip.get_text() {
            app.textarea_mut().insert_str(text);
        }
    }
    // If clipboard unavailable, fall through to textarea internal paste
    // (textarea.paste() uses internal yank buffer)
}
```

**Step 2: Add arboard import to `src/main.rs`:**
```rust

```

**CRITICAL NOTES:**
- Do NOT construct `arboard::Clipboard::new()` at startup or cache it. Construct per-operation only. Clipboard construction involves system calls.
- All clipboard operations wrapped in `if let Ok(...)` — clipboard failure is silent no-op, not fatal error
- This handles Pitfall 2 from RESEARCH.md: SSH/headless environments where clipboard is unavailable
- `textarea.copy()` and `textarea.cut()` work on the CURRENT SELECTION. If nothing is selected, `yank_text()` will return empty string. This is correct — copy with no selection does nothing meaningful.
