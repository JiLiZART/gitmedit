Add the following types and functions to src/document.rs (below the existing ContentLine code, above the Document struct):

1. **RebaseAction enum:**
```rust
#[derive(Debug, Clone, Copy, PartialEq)]
pub enum RebaseAction {
    Pick,
    Squash,
    Fixup,
    Drop,
    Exec,
}
```
With methods:
- `cycle(&self) -> Self`: Pick->Squash->Fixup->Drop->Pick; Exec->Exec (no-op)
- `as_str(&self) -> &str`: returns "pick", "squash", "fixup", "drop", "exec"

2. **RebaseLine enum:**
```rust
#[derive(Debug, Clone, PartialEq)]
pub enum RebaseLine {
    Action {
        action: RebaseAction,
        hash: String,
        subject: String,
    },
    Comment(String),
}
```

3. **parse_action(s: &str) -> Option<RebaseAction>**: matches "pick"|"p" => Pick, "squash"|"s" => Squash, "fixup"|"f" => Fixup, "drop"|"d" => Drop, "exec"|"x" => Exec, _ => None

4. **classify_rebase_line(line: &str, comment_char: char) -> RebaseLine**: If starts with comment_char, return Comment. Otherwise splitn(3, ' '). If first part parses as action and has at least 2 parts after split, return Action variant. Special case: if action is Exec, the "hash" and "subject" don't apply — store everything after "exec " as subject with empty hash. Malformed lines become Comment.

5. **parse_rebase_todo(raw: &str, comment_char: char) -> Vec<RebaseLine>**: Split on '\n', skip trailing empty token (same pattern as Document::parse), classify each line with classify_rebase_line. Return Vec.

6. **serialize_rebase_todo(lines: &[RebaseLine]) -> String**: For each line: Action => "{action.as_str()} {hash} {subject}\n" (or for Exec: "exec {subject}\n"). Comment => "{text}\n". Always output long-form action names. Return concatenated string.

Add unit tests in the `mod tests` block within document.rs for all behaviors listed above.
