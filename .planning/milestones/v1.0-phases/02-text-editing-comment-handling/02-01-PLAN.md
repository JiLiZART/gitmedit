**ContentLine enum:**
```rust
#[derive(Debug, Clone, PartialEq)]
pub enum ContentLine {
    Content(String),
    Comment(String),
    ConflictMarker(String),
}
```

**`read_comment_char()` function:**
- Run `std::process::Command::new("git").args(["config", "--get", "core.commentchar"]).output()`
- If output is Ok and status is success: trim stdout, take first char
- If trimmed output is `"auto"` or empty: return `'#'` (v1 limitation, documented in REQUIREMENTS.md out-of-scope)
- If command fails (git not in PATH, no config set): return `'#'`
- Return type: `char`

**`classify_line(line: &str, comment_char: char) -> ContentLine` function:**
- If `line.starts_with(comment_char)` -> `ContentLine::Comment(line.to_string())`
- Else if `line.starts_with("<<<<<<") || line.starts_with("======") || line.starts_with(">>>>>>")` -> `ContentLine::ConflictMarker(line.to_string())`
  - Use 6-char prefix to catch both 6-char and 7-char git variants
- Else -> `ContentLine::Content(line.to_string())`

**Document struct:**
```rust
pub struct Document {
    lines: Vec<ContentLine>,
    editable_index: Vec<usize>,
    comment_char: char,
}
```
- `editable_index`: maps TextArea row index -> full `lines` Vec index. Built during parse. Contains only indices of `ContentLine::Content` variants.

**`Document::parse(raw: &str, comment_char: char) -> Document`:**
- Split `raw` by `'\n'`
- For each line: call `classify_line(line, comment_char)` and push to `lines`
- Build `editable_index`: iterate `lines` with `.iter().enumerate()`, for each `ContentLine::Content(_)` push the index to `editable_index`
- Handle trailing newline: if `raw` ends with `'\n'`, the last split produces an empty string. This is correct — it becomes `ContentLine::Content("")`.
- Return `Document { lines, editable_index, comment_char }`

**`Document::editable_lines(&self) -> Vec<String>`:**
- Filter `self.lines` to only `ContentLine::Content(s)` variants, clone the inner String
- Return as `Vec<String>`

**`Document::full_row_for_editable(&self, editable_row: usize) -> usize`:**
- Return `self.editable_index[editable_row]`

**`Document::editable_count(&self) -> usize`:**
- Return `self.editable_index.len()`

**`Document::lines(&self) -> &[ContentLine]`:**
- Return `&self.lines`

**`Document::comment_char(&self) -> char`:**
- Return `self.comment_char`

**`Document::serialize(&self, textarea_lines: &[String]) -> String`:**
- Walk `self.lines` in order with a `content_idx: usize = 0` counter
- For `ContentLine::Content(_)`: append `textarea_lines[content_idx]`, increment `content_idx`
- For `ContentLine::Comment(s)` or `ContentLine::ConflictMarker(s)`: append `s`
- After each line append `'\n'`
- Return the assembled String
- CRITICAL: This preserves comment bytes verbatim (CTX-06) and maintains original interleaving order

**`Document::update_content_line(&mut self, editable_row: usize, new_content: String)`:**
- Get full index from `self.editable_index[editable_row]`
- Replace `self.lines[full_idx]` with `ContentLine::Content(new_content)`
