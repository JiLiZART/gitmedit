### IO-06 Regression (HIGH)

`terminal.rs` now calls `EnterAlternateScreen` at line 43 and `LeaveAlternateScreen` in Drop at lines 62-68. This was introduced after Phase 1 verification and violates IO-06 ("Editor does NOT use alternate screen"). Prior terminal output is wiped on launch.

**Secondary bug:** The `Drop` implementation calls `.unwrap()` on `execute!` macro, which will panic if the terminal write fails during Drop.

`help_text_for_context()` has no dedicated `GitContext::Commit` branch — it falls through to the default base action list. Functionally correct (all base actions are relevant to Commit mode), but the intent of HELP-02 ("shows only relevant actions for current mode") is not explicitly satisfied for Commit context.
